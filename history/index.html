第一阶段：网易博客时期 (2011 - 2014)
#

  • 关键词：ACM-ICPC · C/C++ 启蒙 · 算法竞赛 · 华科集训队
  • 时代记忆： 那是中文互联网个人独立博客与空间最繁荣的年代。大一在华中科技大学接触 ACM 算法竞赛，网易博客成为了最初记录日常刷题（POJ、HDU、Codeforces）与解题报告的地方。 那时的文章青涩直接，每一篇都是一个具体的算法问题、一段用 C++ 写的 AC 代码，以及对图论、动态规划、数论的推导。这些文字见证了从零开始敲开计算机体系大门的过程。

第二阶段：博客园时期 (2015 - 2017)
#

  • 关键词：博客园 (cnblogs/111qqz) · 高密度算法刷题 · 算法体系化
  • 时代记忆： 随着竞赛深度增加与研究生阶段的学习，博客搬迁到了技术氛围浓厚的博客园。在这个阶段，刷题量与文章产出迎来了爆发式增长，累计撰写了数百篇算法题解。 不仅关注“如何解出一道题”，更开始关注通用模板的抽象、时间复杂度的常数级优化，以及算法在工程中的边界，积累了扎实的算法直觉与系统底层思维。

第三阶段：WordPress 独立站点时期 (2017 - 2019)
#

  • 关键词：自建独立站 · 111qqz.com · 深度学习 · Caffe 源码 · 经典公开课 · 腾讯与商汤
  • 时代记忆： 从算法竞赛走向工业界，深感需要一个完全属于自己的独立技术阵地，于是注册了域名 111qqz.com，使用 WordPress 自建服务器。 这一时期，人工智能浪潮全面爆发。文章的主题也从单纯的算法，演进为深度学习底层系统：
    • 精读并剖析 Caffe 源码结构与计算流；
    • 研读 MIT 6.828（操作系统）与 CSAPP 等硬核系统公开课；
    • 在腾讯与商汤参与深度学习推理框架、模型服务部署与 GPU 算子优化的工程实战。

第四阶段：Hugo 静态博客与 ML Infra 时期 (2019 - 至今)
#

  • 关键词：Hugo · Blowfish · 量化投资 · AI Infrastructure · PyTorch & Triton · 系统演进
  • 时代记忆： 为了摆脱动态 CMS 的运维负担与安全隐患，2019 年将全部历史博文平滑迁移至 Hugo 静态站点，托管于 GitHub Pages。针对 1290+ 篇历史文章，建立了严格的 URL 映射、内容加密审计与无缝重定向保护。 在工作上，进入量化投资行业，负责带领 AI Infrastructure 团队：
    • 极限压榨 GPU 显存与计算吞吐；
    • 深入 PyTorch 核心、Triton 编译器与大模型分布式并行训练/推理系统；
    • 聚焦工程复杂系统的长生命周期演进与稳定性建设。

☕ 长期主义的技术写作观
#

在信息碎片化、短视频与大模型快速生成的当下，为什么还要坚持手写独立长篇技术博客？

  1. 写给自己看：把一个复杂系统或晦涩 Bug 彻底讲透的过程，本质是一次高密度的认知重构。只有能用清晰语言写下来的知识，才是真正属于自己的。
  2. 连接同路人：博客是一个安静的引力场。它跨越时间与地域，让对底层系统、算法与极限性能抱有纯粹热情的工程师们在此相遇。
  3. 数字生命的年轮：每当回看十多年前写下的代码与文字，就像穿越时光隧道。它们不仅是技术的足迹，也是青春与成长的印记。
