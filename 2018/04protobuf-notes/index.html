Protobuff 是一种轻便高效的结构化数据存储格式，可以用于结构化数据序列化。它很适合做数据存储或 RPC 数据交换格式。可用于通讯协议、数据存储等领域的语言无关、平台无关、可扩展的序列化结构数据格式。

需要注意，如果我们想要修改某个class中的另一个class的单个值，需要用mutable_name()方法，而不是name()方法．参考如下例子：

 1syntax = "proto3";
 2package test;
 3message Feature
 4{
 5    int32 ver = 1;
 6    int32 idx = 2;
 7    int32 len = 3;
 8    repeated float feat = 4;
 9    message Single
10    {
11	int64 QxXx = 1;
12	string imagePath=2;
13    }
14    Single sin = 6;
15}
